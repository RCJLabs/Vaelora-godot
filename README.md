# High-Fantasy Sandbox RPG

Solo-developed Elder Scrolls-style free-form high fantasy sandbox.

- **Tone:** Wondrous and hopeful with real danger
- **Style:** Stylized but grounded
- **Approach:** Start extremely small with a vertical slice / concept demo, expand only after it works
- **Tools:** AI-assisted art and coding + basic programming

## Design Document

The full design plan, pillars, scope, and foundational decisions are in [DESIGN.md](DESIGN.md).

## Current Status

Godot 4 project in [`godot/`](godot): race selection, first-person controller, Health/Stamina/Magicka, skills that improve with use and character levels, inventory/gold/loot, magic (Healing and Flames), save slots with a pause menu and settings, E-to-interact, JSON dialogue, and melee combat against a pathfinding wolf pack, two quests (one with three endings) tracked in a journal, and Riverwatch faction reputation. Guides: [setup & collision](docs/godot-starter/FIRST_PERSON_SETUP.md), [dialogue](docs/godot-starter/DIALOGUE.md), [races](docs/godot-starter/RACES.md), [stats, saving & settings](docs/godot-starter/STATS_AND_SAVING.md), [combat](docs/godot-starter/COMBAT.md), [skills](docs/godot-starter/SKILLS.md), [inventory](docs/godot-starter/INVENTORY.md), [magic](docs/godot-starter/MAGIC.md), [quests](docs/godot-starter/QUESTS.md), [factions](docs/godot-starter/FACTIONS.md), [art & assets](docs/godot-starter/ASSETS.md).
