# Browser Prototype

Minimal vertical-slice prototype built entirely with web technologies (Three.js).

## How to run
1. Download or clone the repo.
2. Open `prototype/index.html` in a modern browser (Chrome, Firefox, Edge).
3. Click the page to lock the mouse, then use WASD to move and click to attack.

## Current features
- Free movement and mouse look
- Small forest clearing with ruins and trees
- Simple real-time combat stub (click near the red enemy)
- Fog and basic lighting for atmosphere

This is a jumping-off point. It can be expanded with better models, textures from concept art, more interactions, and race visuals.
